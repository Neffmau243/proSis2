# Imágenes institucionales de seguros

Descargadas el 12 de octubre de 2026 desde las fichas oficiales de gob.pe:

- `sis.png`: [Seguro Integral de Salud](https://www.gob.pe/sis), imagen «Logotipo de Seguro Integral de Salud» (`logoPNG35.png`).
- `essalud.png`: [Seguro Social de Salud](https://www.gob.pe/essalud), imagen «Logotipo de Seguro Social de Salud» (`essalud 341x86 2019.png`).

Se usan para identificar el seguro seleccionado dentro de la ficha del paciente.
Se conservan los colores y proporciones originales; no se aplica recoloración.
Sanidad y Particular son categorías del catálogo sin una entidad concreta:
se presentan con iconos de Element Plus y etiquetas, sin atribuir una aseguradora.
Todos comparten un marco fijo de 90 × 52 px, conservando las proporciones de
las imágenes oficiales.

La relación entre códigos internos, HIS y contrato SIS está documentada en
`docs/SEGUROS_PERU.md`.
